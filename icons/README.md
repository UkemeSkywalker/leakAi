# Icons Directory

This directory contains the extension icons in various sizes:
- icon16.png (16x16) - Small icon for extension toolbar
- icon32.png (32x32) - Medium icon for extension management
- icon48.png (48x48) - Large icon for extension details
- icon128.png (128x128) - Extra large icon for Chrome Web Store

For now, these are placeholder files. In a production extension, you would replace these with actual PNG icon files.
