LeakAI Content Script Test Page

Testing Instructions:

  1. Open Chrome Developer Tools (F12)
  2. Go to the Console tab
  3. First, run debug test: Copy and paste the contents of debug-test.js into the console
  4. Type in the various input fields below
  5. Try typing sensitive data like emails (test@example.com) or phone numbers (555-123-4567)
  6. Watch the console for LeakAI detection messages
  7. Hover over underlined text to see tooltips with detection details
  8. Click on action buttons in tooltips to test remediation:
    • Mask: Replaces sensitive data with masked version (e.g., j***@example.com)
    • Remove: Deletes the sensitive data completely
    • Replace: Prompts you to enter replacement text
    • Encrypt: Replaces with encrypted token
    • Ignore Once: Temporarily ignores this detection
    • Undo: Reverses the last action (appears after performing an action)
  9. Keyboard shortcut: Press Ctrl+Z (or Cmd+Z on Mac) to undo the last action
Troubleshooting: If nothing appears to work, check the console for error messages. The extension should log "LeakAI data models loaded successfully" and "LeakAI DetectionEngine class loaded successfully" when working correctly.

Expected Visual Results

When you type sensitive data, you should see:

  • Blue underlines for PII (emails, phone numbers)
  • Amber underlines for financial data (credit cards)
  • Red underlines for credentials (API keys, private keys)
  • Purple underlines for crypto addresses and company confidential
  • Gray underlines for low-risk items

The underlines should appear as you type and disappear when you clear the text.

Tooltip Testing: Hover over any underlined text to see a tooltip with:

  • Detection type and risk level
  • Explanation of why it was flagged
  • Detected text and context
  • Available actions (Mask, Remove, Replace, etc.)
  • Undo button (if previous actions were performed)
  • Confidence score

Action Testing: Try these workflows:

  1. Type an email address → hover → click "Mask" → see it become j***@example.com
  2. Type a phone number → hover → click "Remove" → see it disappear
  3. Type a credit card → hover → click "Replace" → enter new text
  4. After any action, hover again → click "Undo" or press Ctrl+Z
  5. Type sensitive data → hover → click "Ignore Once" → see underline disappear
