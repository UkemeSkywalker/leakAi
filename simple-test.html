LeakAI Simple Test

Quick Test Instructions:

  1. Open Chrome Developer Tools (F12)
  2. Go to Console tab
  3. Copy and paste the contents of simple-debug.js into the console and press Enter
  4. Type test data in the input fields below
  5. Look for red underlines on sensitive data
  6. Hover over underlined text to see tooltips
  7. Click action buttons in tooltips

Test Input Fields:

Test Examples to Copy/Paste:

Email: john.doe@example.com

Phone: (555) 123-4567

Credit Card: 4111111111111111

Mixed: Contact me at test@gmail.com or call +1-800-555-0123

Expected Results:

  • Red underlines should appear under sensitive data
  • Tooltips should show when hovering over underlined text
  • Action buttons should work (Mask, Remove, Replace, etc.)
  • Console messages should show detection details

If nothing works: Check console for error messages. The extension should log "LeakAI data models loaded successfully" when working.
